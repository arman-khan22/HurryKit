# HEIC (High Efficiency Image Container)

HEIC is an image container format based on High Efficiency Video Coding (HEVC / H.265). Developed by MPEG and adopted by Apple as the default photo capture format starting with iOS 11, HEIC delivers approximately 50% better compression than standard JPEG at equivalent visual quality.

## Features & Advantages
- **Superior Compression:** High-fidelity images at half the file size of JPEG.
- **Advanced Dynamic Range:** Support for 16-bit color channels compared to JPEG's 8-bit limit.
- **Multi-image Sequences:** Supports live photos, burst shots, and depth maps within a single container.
- **Non-destructive Edits:** Stores crop, rotation, and filter instructions without re-compressing image pixels.
