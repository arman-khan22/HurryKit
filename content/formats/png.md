# PNG (Portable Network Graphics)

PNG is an uncompressed or losslessly compressed raster-graphics format designed to replace GIF with full 24-bit RGB and 32-bit RGBA alpha channel transparency.

## Key Features
- **Alpha Transparency:** 8-bit alpha channel allowing 256 levels of opacity for smooth edges and translucent overlays.
- **Lossless Deflate Compression:** Pixel-perfect reproduction without the compression artifacts of lossy formats.
- **Ideal for UI & Screenshots:** Perfect for logos, illustrations, typography, and computer screenshots.
